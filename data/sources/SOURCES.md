# TANIM Data Source Notes

This file records public data categories and institutions used as references when building TANIM datasets.

The TANIM concept note identifies the following intended source categories:

- PSA OpenSTAT for historical crop production, planted area, and price information
- Department of Agriculture price monitoring
- Supply utilization information
- PAGASA climate information
- Weather API data
- NCCAG crop suitability mapping

TANIM may use synthetic demo data when direct data access is limited.

A source listed here may inform dataset structure, naming, geographic coverage, plausible ranges, or trends. It does not mean that every TANIM-generated numeric value was published by that source.

Add exact dataset titles, retrieval dates, links, transformations, licenses, and notes when source material is collected.
